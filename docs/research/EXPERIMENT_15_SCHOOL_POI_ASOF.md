# Эксперимент 15: учебный период и остановки около школ

**Дата:** 26.09.2026. **Статус:** проверена гипотеза о летнем профиле; влияние близости конкретных школ на прогноз **не измерено**. Никакие факты ноября–декабря не использованы.

## Вход, отсечка, метрика

- Приложенные организаторами `labels_day_train.csv` (январь–август 2025) и `labels_day_test.csv` (сентябрь–октябрь 2025); данные сохранены вне Git. Девять маршрутов с историей: 1, 7, 11, 12, 17, 25, 26, 28, 50.
- На дату **31.08.2025** обучен маршрут × день недели × час профиль. Контроль — 01.09–31.10.2025, **61 последовательный день**, все 24 часа, включая отсутствующие строки целевой таблицы как нули **только для конкурсной метрики**. Для каждого прогнозного часа не подставляется фактическое значение предыдущего дня.
- `WAPE-score = max(0, 1 - Σ|факт - прогноз| / Σфакт)`. Базовый профиль: медиана январь–август, 80% локальный день недели × час и 20% маршрут × час. Проверяемая версия исключает будни июля–августа из обеих статистик, оставляя летние выходные.
- Источник дат учебного года: [Минпросвещения, рекомендации для 2025/26](https://edu.gov.ru/press/10243/nazvany-rekomendovannye-daty-nachala-i-zaversheniya-2025-26-uchebnogo-goda/); это общий календарный контекст, **не локально подтверждённые часы работы школы и не признак конкретной остановки**.

## Парное сравнение

| Вариант | Абсолютная ошибка | Сумма факта | WAPE-score |
| --- | ---: | ---: | ---: |
| Медиана по январю–августу | 1 683 697 | 12 754 481 | 0,867992 |
| Без летних будней | 1 512 710 | 12 754 481 | **0,881398** |

Разница **+0,013406** на том же срезе. Выбор правила был сделан после просмотра сентября–октября, поэтому это исследовательская абляция, а не независимая оценка ноября–декабря. Рост не доказывает именно влияние школ: одновременно изменяются сезонность, маршруты и объём перевозок. Новую конкурсную оценку этой абляции не приписывать.

## Географическая проверка «остановка рядом со школой»

Приложенный справочник `Хакатон_справочники_трамвай_10_маршрутов.xlsx`, лист `Порядок_с_координатами`: 622 строки маршрут–остановка, 315 для девяти размеченных маршрутов; сопоставление с размеченными маршрутами есть только для 1, 7, 11, 12 и в более поздних версиях. Скрипт требует обе даты строки (`start_date` и `actual_date`) не позже отсечки. Итог: **0 допустимых связей** на 30.04, 30.06, 31.08 и 31.10.2025. Даже обнаруженное позднее название остановки «Школа» не даёт ни радиуса до школы, ни посадок на остановке.

Метки содержат только `route;date;hour;boardings`. Исходный `place_id` обозначает площадку/депо, а не `stop_id`. Без версии сети, доступной на дату отсечки, и факта с проверенной остановочной привязкой эффект POI не идентифицируется. Не допускается делить маршрутные валидации равномерно по остановкам. Проверка на 2025 год требует архив `route_id, stop_id, direction_id, valid_from, valid_to`, исторический POI-слой с координатами и датой существования, а затем парную абляцию для одинаковых 61-дневных периодов. Для офисов и больниц нужны собственные классы и часы работы; названия остановок недостаточны.

Кандидаты источников, ещё **не использованные как признаки**: [архив GTFS Transitland](https://www.transit.land/feeds/archive/), [Moscow Transport в Mobility Database](https://mobilitydatabase.org/feeds/gtfs/mdb-3226), [исторический срез OpenStreetMap через Overpass](https://wiki.openstreetmap.org/wiki/OverpassQL). Дата получения снимка и сопоставление маршрутов обязательны; доступность архивной выгрузки уточняется отдельно.

## Воспроизведение

```bash
python docs/research/experiment_15_school_poi.py \
  --train /path/to/labels_day_train.csv \
  --test /path/to/labels_day_test.csv \
  --stops /path/to/Хакатон_справочники_трамвай_10_маршрутов.xlsx \
  --out /tmp/experiment_15_school_poi_asof.json
```

Python 3.12+, `openpyxl`; код и агрегированный JSON находятся рядом с другими опытами. Ожидаемые числа зафиксированы в `results/experiment_15_school_poi_asof.json`. Исходные метки, транзакции и приложенный XLSX не публиковать.

**Решение:** сезонное правило оставить кандидатом; измеренное улучшение от POI не заявлять. На конкурсный горизонт строить все 61 дня сразу; дневная и месячная карточки — агрегация одного ряда. Дальнейшая проверка требует исторического GTFS и остановочных фактов.
