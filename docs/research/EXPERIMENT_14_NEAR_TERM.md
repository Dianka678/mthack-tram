# Опыт 14: почасовой прогноз на день и неделю по последней известной неделе

## Постановка

Из ответов экспертов к задаче: интересуют почасовые прогнозы на день/месяц;
годовой горизонт не обязателен. В фиксированном конкурсном файле сразу на
ноябрь–декабрь фактов внутри периода нет. Здесь отдельно проверен **режим
оперативного обновления**, в котором к началу каждого дня/недели уже получены
метки предыдущей недели. Для него предыдущие наблюдённые значения являются
доступным фактором, а не утечкой. Его WAPE нельзя приписывать исходному
конкурсному файлу с отсечкой 31 октября.

Данные: предоставленные `labels_day_train.csv` и `labels_day_test.csv`, только
девять маршрутов с метками (без 5). Прогноз всегда на все 24 часа. Контроль:
медиана всей истории `route × weekday × hour` с 20% примесью медианы
`route × hour`, переобученная на каждом cutoff. Кандидат: число посадок того
же маршрута и часа **семью днями ранее**. Для прогноза на 7 дней исходные
семь дней целиком предшествуют отсечке. Пропуски ключей только при
расчёте конкурсного WAPE считаются нулями. Нет подстановки истинного
значения внутри прогнозируемой недели.

| Оперативный горизонт и период | Дней | Контроль WAPE-score | Прошлая неделя | Прирост |
| --- | ---: | ---: | ---: | ---: |
| День, 01.07–31.10, обновление ежедневно | 123 | 0,823911 | **0,879991** | **+0,056080** |
| Неделя, 07.07–26.10, 16 неперекрывающихся недель | 112 | 0,818440 | **0,878793** | **+0,060353** |
| День, 01.09–31.10 | 61 | 0,874279 | 0,890684 | +0,016405 |
| Неделя, 01.09–26.10 | 56 | 0,871193 | 0,890194 | +0,019001 |

Суммарная абсолютная ошибка дня на июле–октябре: 4 133 196 → 2 816 859
при сумме фактов 23 472 134. Для недели: 3 844 760 → 2 566 707 при сумме
фактов 21 176 279. Большая часть выигрыша приходится на июль–август, когда
сеть менялась. На сентябре–октябре выигрыш существенно меньше. Кандидаты
сравнивались на известных исследователю метках; результат **исследовательский**,
не оценка независимого финального теста. Число 0,93 пока не достигнуто.

Приоритет внешних факторов для короткого горизонта: выпуск прогноза погоды
по состоянию на cutoff, почасовые осадки/температура и датированные изменения
движения. [Архив отдельных модельных выпусков Open-Meteo](https://open-meteo.com/en/docs/single-runs-api)
потенциально покрывает ECMWF IFS 2025 года на срок до 10 дней; выбирать
выпуск с учётом **задержки публикации после времени инициализации**, иначе
получится утечка. API из текущей среды недоступен, погодные значения не
получены и погодного прироста WAPE в этом опыте нет. Исторического
**маршрутно-часового** ряда трафика в предоставленных файлах также нет;
городской среднемесячный индекс не подменяет наблюдённые пробки вдоль линии.
Поэтому поправки погоды и трафика в прогноз не внесены.

## Воспроизведение

[`experiment_14_near_term.py`](experiment_14_near_term.py) создаёт JSON с
ошибкой по маршрутам и, при явном указании отсечки, CSV для девяти маршрутов.
Пример прогноза 1–7 ноября использует только известные до конца 31 октября
значения 25–31 октября; для полноценной конкурсной сетки на 10 маршрутов
требуется отдельная политика маршрута 5.

```bash
python docs/research/experiment_14_near_term.py \
  --train /path/to/labels_day_train.csv \
  --test /path/to/labels_day_test.csv \
  --out /path/to/near_term_result.json \
  --forecast-cutoff 2025-10-31 --forecast-days 7 \
  --forecast-out /path/to/week_2025-11-01.csv
```
