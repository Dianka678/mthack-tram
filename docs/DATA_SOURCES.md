# Внешние данные и подтверждение эффекта

Баллы за источник предполагаются только при рабочей ссылке **и** сравнении качества с моделью без него. Источник, дата доступа, лицензия, точка времени доступности и ключи соединения должны быть зафиксированы в PR. Наличие ссылки само по себе не подтверждает эффект.

| Фактор | Рабочая отправная ссылка | Получение и временная доступность | Ответственный | Проверка |
|---|---|---|---|---|
| Погода | https://open-meteo.com/en/docs/historical-weather-api | почасовая история по координатам Москвы; для соревнования фактическая погода допустима по Q&A; для честного прогноза использовать архив прогнозов или доступный на дату среза прогноз | DS‑2 | WAPE без/с температурой, осадками, снегом по каждой временной отсечке |
| Календарь | https://government.ru/docs/all/155500/ | постановление о переносе выходных 2025; кодировать будни, праздники, переносы, каникулы отдельно, не брать глобальный `weekend` без проверки | DS‑2 | ablation календарных флагов |
| Дорожные ограничения | https://gucodd.mos.ru/ | проверить историчность/машинный доступ и геопривязку; если нет воспроизводимого ряда, оставить кандидатом, не заявлять балл | DS‑2 | WAPE по затронутым маршрутам и общий WAPE |
| Городские наборы и геометрия | https://data.mos.ru/ | найти точный набор остановок/маршрутов, проверить лицензию, API и соответствие ID; геометрия сама по себе не равно прогностический фактор | Fullstack + DS‑2 | покрытие маршрутов/остановок и точность привязки |
| События и новости | https://transport.mos.ru/ | архивировать публикацию и дату события; извлекать только события, которые известны в соответствующий момент прогноза | DS‑2 | ablation флага событий; иначе исследовательский кандидат |

Форма записи опыта: `source_url`, `fetched_at_msk`, `published_at`, `valid_from/to`, `route_join`, `coverage_%`, `license`, `train_cutoff`, `WAPE_base`, `WAPE_with`, `delta`, `artifact_sha`, `limitations`. Сохранить небольшой список конкретных записей и воспроизводимый скрипт получения, не только ссылку на главную страницу.

Режимы оценки: `competition` может пользоваться фактическими внешними данными ноября–декабря 2025, если это допускают правила; `as_of_2025_10_31` использует только известное на 31 октября и соответствующие архивные прогнозы. В презентации разнести результаты этих режимов.
