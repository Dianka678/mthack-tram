# DS-1 × DS-2: календарь и изменение режима маршрута 50

`ds2_hybrid.py` сохраняет профиль DS‑1: медиана по маршруту, дню недели и часу с 20% сглаживанием к маршруту и часу. Это отдельный воспроизводимый кандидат для сравнения с `CalendarProfile` и бустингом из актуального PR #3, а не замена победителя до оценки на одних и тех же входных файлах. Дополнения из опытов DS‑2:

1. Официальные нерабочие будние дни 2025 трактуются как воскресенье, рабочая суббота 1 ноября — как понедельник. В майско-июньском backtest при отсечении 30 апреля score вырос с 0,798214 до 0,847171.
2. Сценарная опция `--experimental-route50` берёт для выходных маршрута 50 медианный профиль после 6 сентября. При отсечении 30 сентября и проверке октября score всех девяти маршрутов вырос с 0,869963 до 0,882974; score маршрута 50 — с 0,729076 до 0,867457. По исследованию DS‑2 от 26.09 нельзя автоматически переносить это правило на весь ноябрь–декабрь без проверенного расписания. Поэтому опция выключена по умолчанию.

Запуск из корня репозитория (пути к исходным меткам задать локально):

```bash
python3 -m ml.forecast.ds2_hybrid \
  --train 'data/organizer/labels_day_train.csv' \
  --test 'data/organizer/labels_day_test.csv' \
  --sample 'data/organizer/test_submission.csv' \
  --out 'artifacts/ds2-hybrid/submission.csv'
python3 -m ml.submit.adapter \
  --sample 'data/organizer/test_submission.csv' \
  --submission 'artifacts/ds2-hybrid/submission.csv'
```

Ограничения: маршрут 5 отсутствует в истории, прогноз для него нулевой. Октябрьская проверка маршрута 50 использует сведения, доступные к 30 сентября, поэтому её нельзя сравнивать как тот же срез с общей проверкой DS‑1 при отсечении 31 августа. Влияние нерабочих дней ноября–декабря и изменение расписания маршрута 50 после октября не подтверждены фактом; score платформы неизвестен. Новый прогон DS‑1 в PR #3 сообщает WAPE-score 0,995779 на файлах с SHA `16e05d10…`/`50a5cb24…`, тогда как повтор DS‑2 на метках с SHA `20a61009…`/`37479ace…` даёт 0,867992. Эти числа нельзя сопоставлять до сверки происхождения и сумм меток. Сырые данные и CSV в Git не добавлять.

Следующие опыты: временная проверка окна обучения 56/90/180 дней по каждому маршруту; календарь с отдельными классами праздника и рабочего переноса; прогноз остаточной активности маршрута 50 вместо жёсткого нуля; проверка статуса маршрута 5 и его cold start на фактах или допустимых внешних признаках; абляция погоды и ремонта с источником и временем публикации каждого признака. Каждый опыт сравнивать на одинаковом срезе без будущих меток.
