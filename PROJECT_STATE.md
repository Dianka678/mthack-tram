## Неизменяемые решения

- Приоритет: `требованич.docx` → Q&A экспертов → PDF кейса.
- Цель оценки: полный прогноз маршрут × дата × час за 01.11–31.12.2025; train январь–август, локальная проверка сентябрь–октябрь 2025. Шаблон `test_submission.csv`: `route;date;hour;prediction`, 14 640 строк = 10 маршрутов × 61 день × 24 часа. Порядок строк сохранять.
- Целевая величина: число записей с `validation_result == 1` по `ngpt_route` и часу `tran_date_time`; это прокси спроса, **не** доказанная фактическая заполненность вагона. Технологические валидации вне времени работы фильтровать после проверки расписания.
- Контрольная метрика: `max(0, 1 - sum(abs(y - yhat)) / sum(y))` на полной часовой сетке. Локальный backtest ниже — не результат платформы. Baseline 0,48 из PDF не сравнивать напрямую без единого среза.
- Маршрут 5 есть в шаблоне, но отсутствует в исследованных raw train и метках. Стратегию холодного старта, включая допустимость нуля, проверить отдельно; строки маршрута не удалять.
- Стек: Python FastAPI + React/TypeScript + MapLibre/Leaflet + Docker Compose; предрасчёт прогнозов, API читает индексированные агрегаты. SQLite/Parquet на демо, PostgreSQL только при необходимости.

## Подтверждённые результаты исследования

Источник: [отчёт DS‑2 от 26.09](https://github.com/Dianka678/mthack-tram/blob/ds2/research-protocol/docs/research/RESULTS_2026-09-26.md) и [backtest.json](https://github.com/Dianka678/mthack-tram/blob/ds2/research-protocol/docs/research/results/backtest.json) в PR #1. Полный агрегированный `summary.json` получен от владельца данных и в Git не публикуется.

- Потоковый проход всего `train.csv` (7,59 ГБ, `partial_scan=false`): 49 051 926 транзакций, из них 46 913 233 успешных валидации; 0 неисправимых дат события и маршрутов. `labels_day_train.csv`: 46 234 строки, 0 повторов ключей, 46 912 710 посадок. Разница — 15 часовых ключей и 523 события, только 01.09.2025. Сверить raw train + test строго по времени события, прежде чем объявлять ошибку меток.
- Метки train: девять маршрутов, 243 дня января–августа; 6 254 из 52 488 часовых ключей отсутствуют (11,92%). Отсутствие строки не доказывает нулевой спрос. На полном `test.csv` ранее выявлено расхождение 39 успешных событий с метками на границах 01.09 и 01.11; его также требуется сверить.
- Контрольные профили `route × weekday × hour` на девяти маршрутах: обучение до 30.06 → июль–август, WAPE-score 0,783548 (среднее) / 0,739241 (медиана); обучение до 31.08 → сентябрь–октябрь, 0,847404 / 0,867992. Непредставленный в метках час принят за нуль только при локальном расчёте метрики. Score платформы за ноябрь–декабрь неизвестен.
- [Матрица факторов](https://github.com/Dianka678/mthack-tram/blob/ds2/research-protocol/docs/research/FACTOR_MATRIX.md) описывает источники, соединение, временную доступность и парные проверки. Численный эффект внешних источников **не измерен**. `place_id` в исходном CSV обозначает площадку/депо, а не остановку; остановочная детализация по имеющимся меткам не подтверждена.
