## Неизменяемые решения

- Приоритет: `требованич.docx` → Q&A экспертов → PDF кейса.
- Цель оценки: полный прогноз маршрут × дата × час за 01.11–31.12.2025; train январь–август, локальная проверка сентябрь–октябрь 2025 по ответам экспертов. Точная сетка и колонки — из `sample_submission` после получения `dataset.zip`.
- Целевая величина: число успешных валидаций; это прокси спроса, **не** доказанная фактическая заполненность вагона. Внерабочие технологические валидации фильтровать согласно проверенному расписанию.
- Контрольная метрика: `max(0, 1 - sum(abs(y - yhat)) / sum(y))` на фиксированной сетке; baseline 0,48 из PDF. Никаких заявлений о достигнутом результате до измерения.
- Пятый маршрут сохраняется в сабмите; нули допустимы по ответам экспертов, решение записать после локальной оценки.
- Стек: Python FastAPI + React/TypeScript + MapLibre/Leaflet + Docker Compose; предрасчёт прогнозов, API читает индексированные агрегаты. SQLite/Parquet на демо, PostgreSQL только при необходимости.
