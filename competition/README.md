## Результат и метод

`WAPE-score = max(0, 1 - Σ|факт - прогноз| / Σфакт)`. На отложенном по времени срезе **01.09–31.10.2025** при обучении по январю–августу локальный исследовательский score кандидата **0,886109**. Правило затухания для маршрута 7 выбиралось с просмотром этого же среза; оценка не независима и не равна score платформы за ноябрь–декабрь. Известный со слов владельца score **0,87571** принадлежит **другому, ранее загруженному файлу**. Для порога PDF `>0,88` потребуются баллы платформы именно за `submission.csv`.

Модель использует медианный профиль `маршрут × день недели × час` с весом 0,8 и сглаживание `маршрут × час` с весом 0,2; летние будни исключены из профильного обучения. Добавлены календарные типы 01.11, 03–04.11 и 31.12 и ограниченное по времени затухание исследовательского режима маршрута 7. Это прямой многошаговый расчёт, **без подстановки фактических значений целевого периода**. Маршрут 5 есть во всех часах CSV с нулевым допущением cold start, точность которого неизвестна. Числа целые, неотрицательные.

## Воспроизведение за две минуты

Только стандартная библиотека Python 3.12+. Скачайте исходные метки и шаблон из [архива организаторов](https://disk.yandex.ru/d/DiFwlfMOauxjBg), разместите их локально в `data/` под указанными именами. Исходные транзакции, метки и пароли **не публикуются** в Git.

```bash
python3 competition/model.py \
  --train data/labels_day_train.csv \
  --test data/labels_day_test.csv \
  --sample data/test_submission.csv \
  --out /tmp/tram-submission.csv \
  --model-out /tmp/tram-model.json
python3 competition/verify.py --sample data/test_submission.csv \
  --submission /tmp/tram-submission.csv --model /tmp/tram-model.json
```

Проверка уже обученного артефакта без меток:

```bash
python3 competition/model.py --model-in competition/model.json \
  --sample data/test_submission.csv --out /tmp/tram-replay.csv
python3 competition/verify.py --sample data/test_submission.csv \
  --submission /tmp/tram-replay.csv --model competition/model.json
```

Сверьте SHA исходных файлов в [`MANIFEST.json`](MANIFEST.json). При **тех же байтах** шаблона, меток и кода воспроизводятся `model.json` и `submission.csv`; иной релиз входов требует новой проверки. Проверка локально воспроизвела опубликованный CSV побайтно.

## Демо и применение

[Docker-сервис в ветке fullstack](https://github.com/Dianka678/mthack-tram/tree/fullstack/scenario-console/apps/tram-service) показывает карту, маршрутные часы/дни и CSV-экспорт, поддерживает логин и ручную сценарную поправку. [Инструкция запуска](https://github.com/Dianka678/mthack-tram/blob/fullstack/scenario-console/apps/tram-service/README.md): создать `secrets/auth.json`, локально положить `data/forecast.csv`, выполнить `docker compose up --build -d`, открыть `http://127.0.0.1:8080` и `/health`. Этот код пока находится в отдельной ветке и по умолчанию читает **предыдущий прогноз**. Чтобы показать этот кандидат в UI, скопируйте проверенный `competition/submission.csv` в локальный `apps/tram-service/data/forecast.csv` и пересоздайте контейнер. Сервис не переобучает модель.

Для диспетчера прогноз означает ожидаемые **посадки**, а не заполнение салона. Пики помогут проверить выпуск и расписание; решение о вместимости требует данных о рейсах, выходах пассажиров и вместимости вагонов. Статус остановок, внешних факторов и замеров указан прямо в критериях.
