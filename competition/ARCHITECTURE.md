# Архитектура, API и границы демо

```mermaid
flowchart LR
  A["История и шаблон"] --> B["Проверка схемы и отсечки"]
  B --> C["Профили и календарь"]
  C --> D["61-дневный почасовой CSV"]
  D --> E["API и дашборд"]
```

- **ML:** `model.py` (fit/forecast) и `model.json` (сохранённые профили). Скрипт принимает агрегированные организаторами `route;date;hour;boardings`; сырые транзакции, версионирование расписания и проверенные статусы пробоев не входят в этот контур.
- **Граница:** `submission.csv` имеет `route;date;hour;prediction`, `;`, 14 640 уникальных часов, неотрицательные целые. Время локальное `Europe/Moscow`; CSV не содержит столбца часового пояса.
- **Сервис:** [отдельная ветка fullstack](https://github.com/Dianka678/mthack-tram/tree/fullstack/scenario-console/apps/tram-service) — Python HTTP backend, статический frontend, Docker Compose и файловый прогноз. `GET /health`, `POST /api/login`, `GET /api/routes`, `/api/geometry`, `/api/forecast?route=1&date=2025-11-01&period=day&factor=1`, `/api/export`. См. [его README](https://github.com/Dianka678/mthack-tram/blob/fullstack/scenario-console/apps/tram-service/README.md). Чат с погодой/ремонтом справочный, численный сценарий — ручной `factor`.
- **Представления:** график по часам выбранного дня, по дням месяца и карта справочной геометрии части маршрутов; экспорт маршрутного CSV. День/месяц — суммы того же 61-дневного ряда, без получения новых фактов.
- **Остановки:** в комплекте нет проверенного прогноза остановок. Геометрия из позднего справочника не доказывает остановочные значения за 2025 год. Визуальный маршрутный показатель нельзя размазывать по остановкам и называть stop-level ML.
- **Год:** опциональная исследовательская цель PDF; непрерывный годовой ML-артефакт и оценка отсутствуют.

Для демо этого кандидата требуется явно загрузить его CSV в локальный сервис, пересобрать/перезапустить Compose и убедиться в версии на экране. Код сервиса пока не в `main`, публичного доступного URL нет. Ошибки сервиса возвращаются HTTP 4xx с сообщением; пользователь создаёт закрытый файл учётных данных на хосте.
