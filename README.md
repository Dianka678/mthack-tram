# Прогноз загрузки трамвайных маршрутов Москвы

## Комплект для жюри

Откройте **[competition/README.md](competition/README.md)**: конкурсный CSV, код обучения и инференса, обученный артефакт, проверка SHA, критерии PDF, источники и исследования.

Прогноз: все часы **01.11–31.12.2025** сразу, 10 маршрутов, 14 640 строк. Локальная исследовательская оценка текущего кандидата на сентябре–октябре — **0,886109**; результат именно этого файла на конкурсной платформе 0.867

[Docker-сервис и инструкция](https://github.com/Dianka678/mthack-tram/tree/fullstack/scenario-console/apps/tram-service) находятся в отдельной ветке. Он читает локальный CSV; для демонстрации текущей модели требуется положить `competition/submission.csv` в `apps/tram-service/data/forecast.csv` и пересоздать контейнер.

## Команда и исходный план

Приоритет при расхождении материалов: `требованич.docx` → ответы экспертов → PDF кейса. [План](docs/PLAN.md), [правила команды](AGENTS.md), [журнал состояния](PROJECT_STATE.md), [исходные источники](docs/DATA_SOURCES.md). Работа DS1 и DS2 ведётся в отдельных ветках; в `competition/` размещён один проверенный кандидат и ссылки на совместимые исследования.

- Данные организаторов и учётные данные не публикуются в GitHub.
- CSV должен сохранять точные поля, строки и порядок шаблона, включая маршрут 5.
- Сведения о RPS, p95, CPU и RAM публикуются только после реального замера; текущий статус — в [competition/PERFORMANCE.md](competition/PERFORMANCE.md).
- Дедлайн в PDF: 27 сентября, 23:59 МСК; актуальные условия уточняются на платформе.
